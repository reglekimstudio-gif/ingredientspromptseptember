원물 크러시 프롬프트 빌더

과일을 고르면 손에 쥔 원물이 5단계로 으깨지는 매크로 컷 프롬프트가 채워집니다. 물결 프레임도 같은 색으로 함께 나와요.

원본 열기

복사한 코드를 피그마 캔버스에 그대로 붙여넣으면 벡터로 들어옵니다. 선택한 원물 색이 이미 칠해진 상태예요. 5400 × 1350 · 1080씩 5장.

          네거티브
          5장 전부 동일
          
        

        

      


      

        
작업 순서

        
    
          
  1. 1단계 전체 프롬프트 복사 → 이미지 생성 툴에 붙여넣기. 손 모양·네일 마음에 들 때까지 반복
    2. 
          
  2. 확정된 1단계 이미지를 레퍼런스로 넣고 2~5단계를 이어서 생성 (체이닝)
    3. 
          
  3. SVG 코드 복사 → 피그마 캔버스에 붙여넣기. 벡터로 들어옵니다
    4. 
          
  4. 
            바깥 사각형과 물결 도형을 함께 선택 → Subtract ⌥⇧S (option+shift+s)
            물결 자리가 뚫려 창이 됩니다. 뒤에 사진을 깔면 그 모양대로 보이니 누끼가 필요 없습니다.
          
    5. 
          
  5. 
            손 사진 5장을 뚫린 레이어 아래에 배치 — 중심 x = 540 / 1620 / 2700 / 3780 / 4860
            세로 위치와 크기는 5장 모두 동일하게. 하나만 어긋나도 넘길 때 튑니다.
          
    6. 
          
  6. 
            1080 × 1350 프레임 5개를 x = 0부터 1080 간격으로 얹기
            프레임은 넘치는 부분을 자동으로 잘라냅니다. 불리언으로 쪼개지 마세요 — 되돌릴 수 없고 벡터가 망가집니다.
          
    7. 
          
  7. 프레임 5개 선택 → Export PNG 2x
    8. 
        

        
손이 프레임을 뚫고 나오게 하려면 — 손목이 어두운 영역까지 내려오는 연출이 필요할 때만, 누끼한 손 하나를 창 레이어 위에 하나 더 올리세요. 이 겹침이 입체감을 만듭니다.
